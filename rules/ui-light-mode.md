# Interfaces Web

- Prioriza HTML5 semántico, CSS limpio y JavaScript vanilla; usa FastAPI o Flask ligero para el backend cuando haga falta.
- Evita frameworks pesados y dependencias de UI innecesarias.
- Diseña en **Light Mode** por defecto: alto contraste, jerarquía visual clara y estética minimalista funcional.
- Asegura legibilidad y foco visible con teclado; no uses color como único portador de información.
